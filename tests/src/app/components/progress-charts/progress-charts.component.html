Общий прогресс

Описание: Этот график показывает общий прогресс выполнения всех тем.

Как рассчитывается: Процент выполнения = (Количество выполненных тем / Общее количество тем) * 100

Точность: Высокая, так как основана на точном количестве выполненных тем.

Что учитывается: Учитываются все темы, помеченные как выполненные.

Прогноз завершения

Описание: Прогноз даты завершения всех тем на основе текущей скорости.

Как рассчитывается: - Историческая часть: линейная аппроксимация прогресса за последний 21 день
- Прогнозная часть: экстраполяция текущей скорости (тем/день) до 100% выполнения

Точность: Средняя, зависит от стабильности вашей скорости изучения.

Что учитывается: Учитывается текущий прогресс и средняя скорость выполнения тем за последние 2 недели.

Сложность по неделям

Описание: Средняя сложность тем по неделям.

Как рассчитывается: Для каждой недели вычисляется среднее значение сложности всех тем этой недели.

Точность: Зависит от точности оценки сложности каждой темы.

Что учитывается: Учитывается значение сложности, указанное для каждой темы (по шкале от 0 до 100).

Затраты времени по неделям

Описание: Общее время изучения тем по неделям.

Как рассчитывается: Суммируется время, указанное для каждой темы в неделе.

Точность: Зависит от точности оценки времени для каждой темы.

Что учитывается: Учитывается время, указанное для каждой темы (например, "2ч 30мин").

Ежедневный прогресс

Описание: Процент выполнения тем по дням.

Как рассчитывается: Для каждого дня вычисляется процент тем, выполненных в срок (в этот день).

Точность: Высокая, так как основана на точных данных о выполнении.

Что учитывается: Учитываются только темы, выполненные в запланированный день.

Эффективность по неделям

Описание: Эффективность выполнения тем по неделям.

Как рассчитывается: - Выполнено: темы, выполненные в срок
- В работе: темы, запланированные на будущее
- Пропущено: темы, не выполненные в срок

Точность: Высокая, так как основана на точных данных о выполнении.

Что учитывается: Учитывается статус каждой темы (выполнена/в работе/пропущена).
